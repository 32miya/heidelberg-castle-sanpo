# ハイデルベルク城さんぽ

ネッカー川を見下ろす丘の上、赤い砂岩のルネサンスの城跡ハイデルベルク城（ドイツ）を、スマホで歩いて巡る3D散策。世界さんぽシリーズのひとつ（ヴェルサイユ宮殿さんぽ・ノイシュヴァンシュタイン城さんぽと同じ作り）。

- 単一の `index.html`（three.js r128）。GitHub Pages にそのまま置けば動きます。
- 世界さんぽ入口へ戻るボタン（sekai-portal ブロック）入り。

## 歩ける場所
- 旧市街：コルンマルクト（聖母の柱）、ハウプト通り、マルクト広場と聖霊教会、市庁舎
- 古い橋（カール・テオドール橋）と橋の門、橋の猿
- 対岸：蛇の道、哲学者の道、哲学者の庭の展望
- 城への坂道、山岳鉄道（ベルクバーン）に乗れる：コルンマルクト ⇄ 城の駅
- 城：砲台庭園、エリーザベト門、太い塔、イギリス館、堀の橋と門の塔、中庭、井戸の館、ループレヒト館、オットハインリヒ館（屋根のない廃墟・薬事博物館）、フリードリヒ館と礼拝堂、ガラスの広間の館、大テラス（アルタン）、大樽の酒蔵（樽の上の踊り場・ペルケオ像）、火薬塔（爆破された塔）
- 選帝侯の庭園（ホルトゥス・パラティヌス）、父なるライン像、ゲーテの記念の石、シェッフェル・テラス

## 時代の切り替え
- 1618年：黄金時代。館はすべて屋根つき、刺繍花壇と噴水の庭、木組みの町、屋根つきの木の橋
- 1830年ごろ：ロマン主義の廃墟。屋根のないフリードリヒ館、ツタ、画家・学生
- 現在：修復されたフリードリヒ館、薬事博物館、山岳鉄道。夜は「城の炎上と花火」

見どころ札 37枚（時代ごとに違う札あり）、大テラスで「登城の印」。

## 世界さんぽディフェンス（`?td`）
`?td` を付けて開くと、このマップが「世界さんぽディフェンス」（タワー配置型の防衛ゲーム、[defence-castle/world](https://32miya.github.io/defence-castle/world/)）の第1ステージになります。1618年の城が舞台。ゲーム本体は defence-castle リポジトリの `world/` にあり、このページは入口の数行（`TD`）だけを持ちます。
